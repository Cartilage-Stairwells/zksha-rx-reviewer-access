# EXPERIMENT A — FINAL BENCHMARK RESULTS

## Operation Definition

Benchmark: dif_butterfly_three_lane
Operation: Single DIF (Decimation-in-Frequency) radix-2 butterfly pass
  For each pair (a[i], b[i]) with twiddle factor w[i]:
    sum = (a + b) mod p
    y   = (a - b) * w mod p  (via Montgomery multiplication, R = 2^32)
  Input: n = 2^log_n Montgomery-encoded BabyBear field elements (u32)
  Butterfly operations: n/2 per pass
  Prime: p = 0x78000001 = 2^31 - 2^27 + 1 (BabyBear)
  Data layout: data[0..n/2] = a-values, data[n/2..n] = b-values

## Three Lanes

1. Scalar: Pure u32 arithmetic, no SIMD (compiled with target-cpu=x86-64)
   - Uses SSE (128-bit xmm) for partial auto-vectorization of modular add/sub
   - Montgomery multiplication via babybear_mul_reference (scalar 64-bit intermediate)
   - 0 ymm (AVX2) instructions, 0 zmm (AVX-512) instructions in kernel

2. AVX2: Compiler-vectorized via #[target_feature(enable = "avx2")]
   - Same scalar algorithm, compiled with AVX2 target feature
   - 31 ymm (AVX2) instructions in kernel, 0 zmm (AVX-512)
   - NOT a hand-written AVX2 kernel — relies on compiler auto-vectorization

3. AVX-512: Hand-written intrinsics from avx512_butterfly_32bit.rs
   - 16 lanes of 32-bit values per __m512i (zmm)
   - Uses: vpaddd, vpsubd, vpmuludq, vpmullq, vpminud, vpcmpltud, vpermt2ps
   - Masked operations with AVX-512 predicate registers (%k1)
   - Confirmed zmm (AVX-512) instructions in kernel
